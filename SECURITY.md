# Security policy

## Supported versions

Only the latest release receives security fixes.

## Report a vulnerability

Report privately through [GitHub security advisories](https://github.com/boylin0/typomend/security/advisories/new). **Do not open a public issue.**

Include:

- The Typomend version and Windows version.
- What the problem is and what an attacker gains.
- Steps to reproduce, with a minimal example.

Do not include real private text.

## What to expect

You get an acknowledgement within 7 days. Confirmed issues are fixed in a new release, and the advisory credits you unless you ask otherwise.

## Severity

Anything that could read, store or send typed text is treated as high severity.
